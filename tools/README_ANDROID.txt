Installation
------------
Open Apotris.apk to install. Allow installation from your file manager if prompted.
Launch the game and grant audio/storage permissions when prompted.
On Android 11+, enable All files access for Apotris in Android Settings, then restart.
This permission lets Apotris read and write audio and save files in Documents/Apotris,
where you can manage them with a file manager. You can deny it and play using
app-specific storage instead.

Customizing audio
-----------------
Launch once to extract audio, then close the game before editing files.
Use Documents/Apotris/assets/ in internal storage, or the assets/ subfolder
of the storage location reported by the game.
Supported music formats: .mod, .it, .xm, .s3m, .mp3, .ogg (Vorbis), .flac, .wav.
Add music directly to this folder. Use lowercase extensions and prefix filenames
with MENU_ for menus or GAME_ for gameplay.
To replace a sound effect, replace its .wav file with one of the exact same name.
Restart to load changes. Preview or disable songs in Settings > Audio > Track List.
Remove custom songs by deleting their files. Disable bundled songs in Track List
instead of deleting them: missing bundled files are restored automatically.
Back up replaced bundled files; asset extraction can overwrite them.
